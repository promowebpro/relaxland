# Admin content backlog

Этот файл фиксирует контент, который в текущем visual-alignment этапе временно задан в шаблоне, но перед production должен редактироваться из административной панели.

## Уже редактируется

| Контент | Источник |
|---|---|
| Телефон в шапке и подвале | `contacts.sales_phone` / `contacts.phone`; на главной временные fallback из макета показываются только при пустых настройках |
| Часы работы в шапке и подвале | `contacts.working_hours`; на главной временный fallback из макета показывается только при пустой настройке |
| Email, адрес офиса и адрес посёлка | `contacts.*`; на главной временные fallback из макета показываются только при пустых настройках |
| Ссылки на маршруты | `routes.yandex`, `routes.google`, `routes.two_gis` |
| SEO-заголовок, description и OG image главной | `HomePage` |
| Изображение первого экрана | `HomePage.hero_image` / `hero_image_mobile` |
| Пять слайдов «Забота и сервис» | `HomePage.care_items`: заголовок, пункты списка, примечание, preset/загружаемые изображения, alt и иконка |

## Перенести в админку

| Блок | Временно задано в шаблоне | Нужная модель редактирования |
|---|---|---|
| Вступление | Заголовок, четыре подписи и ценовая сноска | Заголовок + repeater карточек с desktop/mobile image, alt, caption, note |
| Цитаты | Два текста, автор и японская подпись | Повторяемые quote-блоки |
| Сценарии дня | Заголовок, шесть сценариев («Пробежка», «Коворкинг», «Прогулки», «Питомец», «Рыбалка», «Баня»), время суток и подписи | Упорядоченный repeater сценариев с временем суток, desktop/mobile изображениями, alt и подписью |
| Сезоны | Общий заголовок, карточки лета и зимы | Repeater сезонов с изображениями, лидом и подписью |
| Главный генплан | Заголовок, описание и подпись локации | Поля промо-блока генплана; данные участков остаются в существующем domain layer |
| Варианты приобретения | Четыре названия и иконки | Repeater способов приобретения |
| Истории | Тексты отзывов, имена, подписи, облака-эмоции и демонстрационные изображения | Расширить `Story`: тип карточки, автор, роль, эмоция, media, позиция/вариант отображения |
| Приглашение на экскурсию | Заголовок, текст, benefit chips и дорожная подсказка | Поля visit-блока; адрес и route links уже берутся из settings |
| Девелопер | Второй абзац, показатель `25+`, подпись | Поля about/developer блока и числовой показатель |
| Превью блога | Демонстрационные подписи и композиционные изображения | Использовать опубликованные `BlogPost`, добавить presentation variant / featured position |
| Подпись автора сайта | «Сайт сделали МОИ» | Добавить настройку footer credit/link |

## Правило следующего этапа

Визуальные значения из утверждённого макета должны стать seed/default content, а Blade не должен оставаться единственным источником изменяемого текста. При переносе необходимо сохранить текущую HTML-структуру и CSS-модификаторы, чтобы подключение админки не изменило согласованный внешний вид.
